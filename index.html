How this works
  • Export your REDCap project (or Excel-based collection sheet) as CSV, one row per facility.
  • On import, the dashboard tries to auto-match your column headers to the fields it needs (facility name, district, domain scores D1–D10, infrastructure items, etc).
  • You'll get a quick mapping screen to confirm or fix any matches before the dashboard builds.
  • Any Yes / Partially / No item column you leave unmapped is automatically picked up as a "critical gap" indicator.
  • Not sure of the exact format? Download the CSV template above — it lists every field name this tool understands.
